Zator Browser Feedback

Beta, observe and retry only. Eligible network failures are sent to your paired LAN router. Successful visits and page paths are not collected.

Site error monitoring

Monitoring needs permission to read network error metadata on sites you visit. It does not read page contents, cookies, or request bodies.

Googlevideo media evidence

Optional and off by default. During an active Googlevideo trial, the extension can sample whether one visible video is progressing or stalling. It sends only coarse playback metrics to the paired router; it does not read video URLs, page paths, titles, or content. These metrics never create or remove a Ramp exemption by themselves.

A Ramp canary may temporarily bypass Ramp for new connections and can disrupt playback. It is a separate opt-in and requires media quality sampling above. The router also requires Ramp pool consent and supported hardware.

Paired router

The token stays in trusted extension storage and is sent only to the router address above. It is never sent to websites or statistics services.
