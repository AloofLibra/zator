Zator Browser Feedback

Beta, observe and retry only. Eligible network failures are sent to your paired LAN router. The extension does not collect successful visits or page paths.

Site error monitoring

Monitoring needs permission to read network error metadata on sites you visit. It does not read page contents, cookies, or request bodies.

Paired router

The token stays in trusted extension storage and is sent only to the router address above. It is never sent to websites or statistics services.
