## Compatibility constraints confirmed in source

- `adaptive.cgi` is authenticated with the Windows-agent pairing token and exposes probe lease/result actions; the browser API must not share that credential or mutate those actions.
- The local adaptive rule row is `version, host, IPv4, profile, proto, scope, strategy, fingerprint, catalog, runtime_stamp, expiry`. Existing readers and snapshots must remain valid during any extension.
- `orchestra/locked.lua` resolves adaptive trial/rule selection for TCP/443 TLS and eligible profile-5 QUIC Initial flows; manual/profile locks take precedence. QUIC has software tests only, not hardware browser-flow acceptance.
- Active browser attempts are correlated with a new SYN/QUIC Initial and selected fingerprint in a bounded tmpfs flow row. This software correlation does not prove that Chrome used that exact flow under H2/H3 multiplexing on each platform.
- Existing HTTP status, isolated curl success, q65535 ACK, and browser success without protocol proof are distinct evidence and cannot be substituted for one another.
