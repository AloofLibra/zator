Проба

Сценарий YouTube использует оба профиля: 1 — страница, 2 — видео. Список номеров применяется к каждому из них.

YT и GV включаются одновременно. Если страница не открылась, меняется только YT; GV ещё не проверена. Оставшиеся GV проверяются с успешной YT.

Все стратегии берутся из живого конфига. Проход последовательный; каждый RKN-сайт проверяется всеми номерами. Авторизация Discord может дать UNKNOWN; body подтверждает только загрузку DOM.

После OK — пауза 5 с. Иначе 15 с, RKN — 30 с. Для YT/GV ускорение требует успеха обеих проверок. Таймаут и отказ загрузки не повторяются.

DIRECT проверяется первым. Без доказанной изоляции результат INVALID; без функционального условия — UNKNOWN. QUIC, UDP, IPv6 и WebRTC не проверяются.
